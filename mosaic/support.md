# サポート：MosaicEditor（モザイク）

iPhone アプリ「MosaicEditor」（ホーム画面の表示名「モザイク」）のサポートページです。

## お問い合わせ

不具合の報告やご質問は、GitHub の Issues で受け付けています。

**[お問い合わせを書く（GitHub Issues）](https://github.com/mashi727/mashi727.github.io/issues/new?template=mosaic.yml)**

- 書き込みには GitHub のアカウント（無料）が必要です。
- Issues の内容は誰でも見られます。**氏名・住所・電話番号などの個人情報や、他人が写った写真は書き込まないでください。**
- 個人で開発しているため、お返事に時間がかかることがあります。

## よくある質問

### 範囲を選んだのに、モザイクがかかりません
範囲を選んだだけでは加工されません。画面下の「モザイクをかける」（ぼかしのときは「ぼかす」）を押すと、選んだ範囲がまとめて加工されます。

### 選んだ範囲の一部だけ、加工せずに残したい
残したい範囲をタップして編集対象（青い枠）にし、「外す」を押してください。外した範囲は点線で表示され、加工されません。「戻す」で元に戻せます。

### 住所や電話番号を隠すには、どの効果がよいですか
「塗りつぶし」をおすすめします。モザイクやぼかしは、条件によっては元の文字を推測される場合があります。塗りつぶしは単色で上書きするため、元に戻せません。

### 写真を拡大して、細かいところを選びたい
2 本指で広げると拡大、2 本指でドラッグすると移動します。ダブルタップでも拡大と全体表示を切り替えられます。

### 選んだ範囲を直したい
四角や自由曲線は、枠の内側をドラッグすると移動できます。四角は角のハンドルで大きさを変えられます。別の範囲をタップすると、その範囲が編集対象になります。

### 写真に保存できません
写真ライブラリへの追加が許可されていない可能性があります。iPhone の「設定」→「プライバシーとセキュリティ」→「写真」→「モザイク」で、「写真の追加のみ」を選んでください。

### 加工を取り消したい
画面右上の取り消しボタン（↶）で、最大 20 回まで戻せます。最初の状態に戻すときは、右上の「…」から「元に戻す（すべて）」を選びます。

## 動作環境

iPhone（iOS 17 以降）
