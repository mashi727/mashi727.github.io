# MosaicEditor（モザイク）

写真の見せたくない部分を、指で選んでモザイク・ぼかし・塗りつぶしで隠す iPhone アプリです。ホーム画面には「モザイク」と表示されます。

- 四角・自由曲線・ブラシの 3 通りで範囲を選べます
- 選んだ範囲は、位置や大きさを直してからまとめて加工できます。一部だけ「外す」こともできます
- 効果はモザイク・ぼかし・塗りつぶしの 3 種類。住所や電話番号などの文字には、元に戻せない塗りつぶしが確実です
- 画像の処理はすべて端末内で行い、外部には送信しません

対応機種：iPhone（iOS 17 以降）／価格：無料
